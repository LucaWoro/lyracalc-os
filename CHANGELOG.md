# Changelog

## 0.7.0-beta

First public release.

- Ubuntu 24.04 armhf with the Luckfox kernel 6.1.99 and patched PicoCalc drivers
- Status bar with `/dev/fb_overlay`, battery warnings and automatic shutdown
- Setup wizard, `/etc/picocalc.conf` with `picocalc-config` and `picocalc-apply`
- WiFi, Bluetooth, USB LAN and tethering commands; driver pack for many USB WiFi sticks
- PICO-8 launcher, installer, game mode and keyboard mouse; TIC-80 built in
- Sound driver with standby and soft fades
- Second SD card slot with automount
- File manager, font selection, app installer, offline cheat sheets, code checking in micro
- ESP32 / MicroPython flashing
- Login picture and info screen with network addresses
